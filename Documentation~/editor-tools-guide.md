# SDK 验证与本地区域地块编辑器 · 操作说明

> 适用版本：MyVerse XR SDK **3.1.4+**。本文面向接入方，讲两个 Editor 工具的完整操作流程：
> **SDK 验证面板**（凭据验证，远端能力的前置门禁）与**本地区域地块编辑器**（制作区域对齐用的地块数据）。
> 设计与运行时原理见开发指南 §6.2 / §12。

---

## 1. 前置准备：开发者平台

两个工具的远端能力（拉取区域规格列表、上传地块数据）都依赖开发者平台的凭据。开始前需要：

1. **在开发者平台创建游戏**——创建完成后平台会生成本游戏的 **AppId** 与 **AccessToken**，两者都在创建游戏时获得。
2. 记下**开发者平台地址**（即验证面板里要填的"服务器地址"）：
   - 联调环境：`http://172.0.0.218:3888`（面板默认已预填）
   - 正式环境：以运维/后端提供的地址为准，在面板里改掉即可

**AccessToken 重要特性**（来自开发者平台的令牌机制）：

- 长期有效（可设置有效期，默认永久）；
- **一个开发者同一时刻只有一枚有效令牌**——在平台重新生成后，旧令牌**立即失效**；
- 团队共用同一枚令牌（见 §2.4 凭据存储），有人重新生成后全员需要更新并重新验证。

## 2. SDK 验证面板

### 2.1 打开方式

- **自动弹出**：导入 SDK 或打开工程时，若本项目尚未验证通过，面板会自动弹出（每个编辑器会话最多提示一次，编译脚本不重复打扰）；
- **手动打开**：菜单 **MyVerse → XRSDK → SDK 验证**。

### 2.2 填写与验证

| 输入项 | 填什么 |
|--------|--------|
| 服务器地址 | 开发者平台地址（默认联调环境，正式环境时改掉） |
| AppId | 开发者平台创建游戏时生成的游戏 id |
| AccessToken | 开发者平台创建游戏时生成的 API 令牌（密码态显示） |

点**验证**：SDK 会调开发者平台接口校验令牌有效性，按钮显示"验证中…"期间请勿关闭窗口。

- **通过**：弹"验证通过"，凭据落盘（见 §2.4），面板此后不再自动弹出；
- **失败**：面板内红色提示原因，对照下表处理。

### 2.3 失败原因对照

| 提示 | 原因与处理 |
|------|-----------|
| appId 与 AccessToken 不能为空 | 两项都必填 |
| AccessToken 无效（签名/格式错误或非 API 令牌） | 令牌复制不完整/贴错了别的令牌，回平台重新复制 |
| AccessToken 已过期 | 到开发者平台重新生成 |
| AccessToken 已被重新生成或作废 | 有人在平台重新生成过令牌，向队友要最新的一枚 |
| 网络请求失败：… | 服务器地址填错 / 平台服务未启动 / 网络不通 |

### 2.4 凭据存储与团队共享

验证通过后凭据写入 **`Assets/MVXRSDK/MVXRSDKSettings.asset`**（不存在会自动创建）：

- 该资产**随项目入 git**——团队共享凭据，一人验证全员生效；
- 刻意**不放 Resources/**，凭据只供编辑器工具链使用，不会打进真机包；
- 重新验证会覆盖已保存的凭据（面板会回填当前值便于查看/更新）。

## 3. 本地区域地块编辑器

### 3.1 用途

制作"本地区域数据列表"资产（地块条目：id / 长 / 宽 / 位置 / 旋转）。运行时 SDK 用中控下发的区域长宽生成临时 id 匹配本地地块条目，按区域公式驱动场景根节点——**地块就是"远端区域在本场景里的摆放标定"**。

### 3.2 创建编辑器对象

Hierarchy 右键 → **MyVerse → 生成本地区域地块编辑器**。

- 生成的对象 tag=EditorOnly，打包自动剔除，不影响真机；
- 工程里已有区域配置文件时会自动挂到"当前配置文件"槽位。

### 3.3 配置文件（数据资产）

- Inspector 顶部"当前配置文件"槽位：指定已有资产，或点**新建**自动创建到契约路径；
- **契约路径**：任一 Resources 根下的 `MVXRSDK/LocalRegionData.asset`（如 `Assets/Resources/MVXRSDK/LocalRegionData.asset`）——运行时按固定路径加载，放错位置工具会给警告、运行时加载不到。

### 3.4 创建条目

1. 点**创建新条目**（未验证会被拦截并引导打开验证面板；拉取期间按钮显示"拉取中…"）；
2. 弹出**远端规格列表**菜单——条目 id 只能从这里选（id 即远端 tagId，`宽x长` 小写格式，如 `4x6`）：
   - 本地已有的 id **置灰不可选**（含未保存的新建草稿）；
   - 远端列表为空会弹提示（确认平台已为该 AppId 配置区域规格）；
   - 拉取失败弹错误，可再次点击重试；
3. 选中后进入编辑态，长宽默认取远端下发的尺寸，位置/旋转为零。

### 3.5 编辑

**编辑区域**（列表下方独立区块，标题区分"新建条目/编辑条目"）：

| 字段 | 含义 |
|------|------|
| 长（米，本地Z轴） | 地块 Z 向尺寸 |
| 宽（米，本地X轴） | 地块 X 向尺寸 |
| 位置 | 地块中心在场景中的位置 |
| 旋转（欧拉角） | 地块朝向 |

- **SceneView 可视化编辑**：编辑中的地块显示蓝色半透明底框 + 位移/旋转手柄，直接拖拽调整；
- **常显选中地块**开关（Inspector 顶部，默认开）：不选中编辑器对象时，编辑中的地块也以橙色描边 + id 标签常显在 Scene 里（受 Scene 视图右上角 Gizmos 总开关控制）；
- 长宽可改，**id 不可改**（运行时匹配键）；
- 有未保存修改时切换条目/取消会弹确认提示。

**摆放建议**：区域对齐是**世界层级刚体变换**。地块 `position` 参与对齐时是**世界层级直接相减**（与区域 A 同级，不被区域旋转带动）；地块 `rotation` **不参与根节点对齐**（只影响地块可视物显示朝向）。根节点朝向由远端区域 rotation + gameOffsetRotation 决定。

### 3.6 保存（上传门禁）

点**保存**：数据先上传开发者平台，**上传成功才写入本地资产**——

- 上传期间整个面板冻结（顶部显示"正在上传地块数据…"），SceneView 拖拽同步冻结；
- 成功：弹"保存成功"，条目进入列表；
- 失败：弹"上传失败"及原因，**本地不落盘**，工作副本保留可修改后重试。

> 注意：后端当前为追加插入，同一 id 重复保存会在服务端累积多条记录（后端待做去重），编辑确认好再保存。

### 3.7 条目列表与删除

- 列表固定五行高，超出滚动；支持按 id 搜索过滤；
- 正在编辑的行蓝色高亮（▶ 前缀），新建未保存的草稿在列表尾部显示橙黄"未保存"行（标题计数 +1 未保存）；
- **删除**仅删本地资产，不同步远端；删除正在编辑的条目会自动退出编辑态。

## 4. 运行时匹配原理（速览）

- 中控下发区域长宽 → SDK 取**绝对值截断取整**（不四舍五入）拼成临时 id（`宽x长` 小写，如远端 len:6.2/width:4 → `4x6`）；
- 临时 id 与本地地块条目 id **精确比对**（大小写敏感）——所以条目 id 必须原样来自远端规格列表，不要手改；
- 匹配成功 → 按区域公式计算并驱动场景根节点（日志 `Region 计算完成[4x6]: …`）；
- 匹配失败 → 根节点保持原位，日志给出含长宽/临时 id/本地条目数的 Warning——排查先看这条。

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| 点"创建新条目"提示需要 SDK 验证 | 先完成 §2 验证 |
| 接口报 `[10006] AccessToken 已失效` | 令牌被重新生成过，用最新令牌重新验证 |
| 上传报 `[10007] 游戏不存在或无权限` | AppId 不属于当前令牌的开发者账号，核对创建游戏时生成的这一对 appId/token |
| 菜单里找不到 MyVerse 入口 | SDK 版本需 ≥3.1.4；Package Manager 刷新包后重启编译 |
| 运行时日志"Region 快照无匹配地片" | 本地条目 id 与远端长宽生成的临时 id 对不上：确认条目从规格列表创建、未手改 id、资产在契约路径 |
| 运行时日志"本地区域数据列表加载失败" | 资产不在 `Resources/MVXRSDK/LocalRegionData` 契约路径 |
